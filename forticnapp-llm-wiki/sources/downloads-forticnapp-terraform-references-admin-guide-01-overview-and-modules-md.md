## Summary (first paragraph of source)

For complex integration scenarios or organizations that prefer to store configuration in source control, you can choose to manually create a main.tf file and use the FortiCNAPP Terraform modules. This method provides a repeatable, collaborative configuration mechanism for managing your security infrastructure as code.
