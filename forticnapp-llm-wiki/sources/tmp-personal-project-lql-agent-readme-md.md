## Summary (first paragraph of source)

Turns natural-language cloud-security questions into validated, executable FortiCNAPP LQL queries. The agent grounds itself on the **live tenant schema** via the `lacework` CLI, generates LQL, and **always validates before presenting** — an unvalidated query is never shown to the user.
