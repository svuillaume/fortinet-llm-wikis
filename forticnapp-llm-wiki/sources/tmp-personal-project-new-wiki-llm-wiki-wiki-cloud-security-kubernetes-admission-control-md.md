## Summary (first paragraph of source)

**Summary:** Kubernetes Admission Controllers are webhook-based mechanisms that intercept requests to the API server before they are persisted. FortiCNAPP uses ValidatingAdmissionWebhook to scan container images for vulnerabilities before deployment, enforcing a policy that only secure images reach production.
