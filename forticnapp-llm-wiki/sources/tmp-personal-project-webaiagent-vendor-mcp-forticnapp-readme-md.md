## Summary (first paragraph of source)

An MCP (Model Context Protocol) server that exposes FortiCNAPP (formerly Lacework) API 2.0 operations as typed, auth-aware tools over stdio. Tools aren't hand-written: they're generated at startup from the bundled OpenAPI spec (`lw.yaml`), so the tool surface tracks the spec you point it at.
