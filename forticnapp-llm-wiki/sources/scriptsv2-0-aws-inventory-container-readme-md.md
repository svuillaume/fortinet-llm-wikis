## Summary (first paragraph of source)

A containerized FastAPI service that wraps `lw_aws_inventory.sh` and exposes an asynchronous HTTP API for collecting EC2, ECS Fargate, and Lambda vCPU inventory across one or more AWS accounts or an entire AWS Organization.
