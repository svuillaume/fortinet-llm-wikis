## Summary (first paragraph of source)

An MCP (Model Context Protocol) server for the [FortiCNAPP (Lacework) API v2](https://docs.fortinet.com/document/lacework-forticnapp/latest/api-reference/). It dynamically generates **173 tools** from the OpenAPI spec at startup — one per API endpoint — so any AI client that supports MCP (Claude Desktop, Cursor, etc.) can query your FortiCNAPP account directly.
