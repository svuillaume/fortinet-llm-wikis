## Summary (first paragraph of source)

A terminal agent that launches any stdio MCP server as a subprocess, discovers its tools at runtime, and drives them from natural language. Pass a question and it runs the Anthropic tool-use loop until it has an answer — calling whatever tools the server exposes, routing around write-gated tools unless `--allow-write` is set, and returning a structured prose response.
