## Overview

Five customer-facing narratives anchor this topic. Each one is written for a specific audience, carries a single core claim, and lands on one hero proof-point that pre-sales, SOC, and field teams can quote verbatim.

**GenAI security positioning.** Audience: CISOs, security architects, and cloud-platform leaders evaluating risk introduced by LLM, RAG, and MCP adoption [src: genai-security-blog.md]. Core claim: GenAI does not replace the security fundamentals — it stacks new concerns on top of them across five layers (developer endpoint, LLM API consumption, RAG pipeline, MCP integration, and cloud and model infrastructure) and the Fortinet Security Fabric, extended with FortiAIGate as the AI-runtime control plane, maps cleanly to each layer [src: genai-security-blog.md]. Hero proof-point: EchoLeak (CVE-2025-32711, June 2025) — Aim Labs disclosed the first known zero-click prompt injection in a production LLM system, where a crafted email caused Microsoft 365 Copilot to retrieve, execute, and exfiltrate internal documents with no user interaction, forcing an emergency Microsoft patch [src: genai-security-blog.md].

**Polygraph FAQ.** Audience: PreSales SEs, Security Architects, SOC Analysts, and DevSecOps teams who need to answer "how does FortiCNAPP detect what no signature has ever named?" [src: FortiCNAPP-TechTip-Polygraph-FAQ.md]. Core claim: Polygraph is a patented, zero-touch behavioral ML engine that models every entity in a cloud environment as a graph, applies unsupervised ML across 13 analysis groups, and detects threats by deviation from a per-workload baseline — no rules, no policies, no signatures, no manual tuning [src: FortiCNAPP-TechTip-Polygraph-FAQ.md]. Hero proof-point: a Forrester Total Economic Impact study found Polygraph establishes a working behavioral baseline in approximately one to two weeks versus six to twelve months for conventional tools, delivering up to 86% alert volume reduction, about 95% false-positive elimination, and 80% faster triage — demonstrated most vividly when Polygraph detected Log4j-related anomalous behavior in customer environments before public disclosure of the vulnerability [src: FortiCNAPP-TechTip-Polygraph-FAQ.md].

**RiskSCORE blog.** Audience: cloud security engineers and SOC analysts triaging FortiCNAPP vulnerability findings who need a repeatable way to decide what to fix first [src: forticnapp-riskscore-blog.md]. Core claim: RiskSCORE blends vulnerability severity, asset criticality, attack surface, and exploitability into one 0–10 score per asset so teams rank by blast radius, not raw CVSS — a CVSS 9.0 in an internal dev sandbox scores lower than a CVSS 6.0 on an internet-exposed production payment processor [src: forticnapp-riskscore-blog.md]. Hero proof-point: without RiskSCORE a single environment can produce 50,000+ alerts per week; with it, focus narrows to the roughly 2–3% of findings — about the top 100 — that actually threaten the business, converting alert fatigue into a measurable, week-over-week downward trajectory [src: forticnapp-riskscore-blog.md].

**AI Assist acceleration.** Audience: SOC analysts facing burnout and the cybersecurity skills gap who need to move from alert to action without being detection engineers [src: community-fortinet-com-blogs-103-forticnapp-ai-assist-accele-3dcda8.txt]. Core claim: AI Assist opens with action-oriented options (Triage, Incident Report, Remediate), correlates context across entities and timelines, produces ranked structured summaries with explicit confidence reasoning and "could this be legitimate?" checks, and generates remediation grounded in the specific alert — "isolate host ip-10-123-45-67 … pending forensic review of the reverse shell observed at 13:01 UTC," not "consider network isolation" [src: community-fortinet-com-blogs-103-forticnapp-ai-assist-accele-3dcda8.txt]. Hero proof-point: the RiskWatch case study — FortiCNAPP's runtime vulnerability detection correlated by composite alerts and surfaced through AI Assist identified and helped remediate two production applications running vulnerable code within hours of the first probes going live [src: community-fortinet-com-blogs-103-forticnapp-ai-assist-accele-3dcda8.txt].

**Shift-Left / Shield-Right messaging.** Audience: cloud and security decision-makers attending the MTL Tech Expo 2026 session (20 minutes) [src: subject.md]. Core claim: modern cloud attacks rarely happen because a firewall failed, so organizations need to Shift Left with DevSecOps security and Shield Right with runtime and network protection by combining CNAPP with the Fortinet Security Fabric [src: subject.md]. Hero proof-point: the session's own target-product stack — FortiCNAPP, FortiGate, FortiWeb, and FortiAnalyzer — presented as one unified narrative from code to runtime to network in a single 20-minute talk [src: subject.md].

### Feedback loops and ML for intrusion detection (newly ingested, 2026-10-16)

**Feedback-loop blog (David Adamson, Fortinet; publication date not stated in the clipping).** Audience: security engineers and SOC teams who want to know how FortiCNAPP keeps alert precision high. Core claim: Composite Alerts score many signals (threat behaviors, IOCs, anomalies) together, and customer labels on closed alerts (true positive, false positive, false negative) feed a training corpus that retrains the scoring models, so detection improves without hand-tuned rules. Every candidate build is tested nightly for precision and recall on labeled scenarios and for alert rate on recent telemetry, and meets release thresholds before shipping. The post gives no numeric results. Detail is in `topics/cwpp/index.md` (Composite Alerts and the feedback loop). `(src: user-upload-fortinet-blog-feedback-loops-intrusion-detection-2026-10-16)`
