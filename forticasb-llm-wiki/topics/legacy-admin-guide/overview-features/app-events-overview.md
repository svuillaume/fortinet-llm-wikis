# App Events Supported by FortiCASB (Legacy 24.4.b)

The guide lists the cloud account event types FortiCASB supports. These events are traced on the **Activity** page of each cloud application and can be used as criteria when configuring policies and applying filters. File Download events are monitored within the FortiCASB Audit log (**Overview > Audit Log**). Screenshots were not extracted. [src: forticasb-admin-guide-24-4-b, p.324]
