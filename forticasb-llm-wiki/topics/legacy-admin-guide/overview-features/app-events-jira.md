# Jira Events

Events traced on the cloud app's Activity page; usable as criteria in policies and filters. Table reconstructed from wrapped PDF text; screenshots not extracted. 

| Event Type | Event | Description |
|---|---|---|
| User Activity | User login | A user has logged in. |
| User Activity | User login failure | A user log in has failed. |
| User Activity | User logout | A user has logged out. |
| User Activity | Create user | A user has been created. |
| User Activity | Update user | A user profile has been updated. |
| User Activity | Delete user | A user is deleted. |
| File Activity | File created | A file attachment is created on the project or issue. |
| File Activity | File deleted | A file attachment is deleted from the project or issue. |
| Issue Activity | Issue created | An issue is created. |
| Issue Activity | Issue updated | An issue is updated. |
| Issue Activity | Issue deleted | An issue has been deleted. |
| Comment Activity | Comment created | A comment is created. |
| Comment Activity | Comment updated | A comment is updated. |
| Comment Activity | Comment deleted | A comment is deleted. |
