# ServiceNow Events

Events traced on the cloud app's Activity page; usable as criteria in policies and filters. Table reconstructed from wrapped PDF text; screenshots not extracted. 

| Event Type | Event | Description |
|---|---|---|
| Login | Login Success | A user has logged in successfully |
| Login | Login Failed | A user login failed |
| Login | Logout | A user has logged out |
| User | Create User | A user has been created |
| User | Delete User | A user has been deleted |
| User | Modify User | Modify user's attribution |
| User | Restore user | Recover a deleted user |
| User | Change Password | Change user's login password |
| User | Add User Role | Add user's role |
| User | Delete User Role | Delete user's role |
| User | Add User to Group | Add a user to selected group |
| User | Remove User from Group | Remove user from the selected group |
| User | Add Group Role | Add group's role |
| User | Delete Group Role | Delete group's role |
| File | Upload File | Upload a file in the table |
| File | Rename File | Rename a file |
| File | Download File | Download a file |
| File | Delete File | Delete a file |
