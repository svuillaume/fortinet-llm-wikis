# Webex Teams Events

Events traced on the cloud app's Activity page; usable as criteria in policies and filters. Table reconstructed from wrapped PDF text; screenshots not extracted. 

| Event Type | Event | Description |
|---|---|---|
| User Activity | User login | A user log into to Webex. |
| User Activity | Create user | A user is created. |
| User Activity | Delete user | A user is deleted. |
| User Activity | Create memberships | Add someone to a room by Person ID or email address. |
| User Activity | Delete memberships | Deletes a membership by ID. |
| User Activity | Update memberships | Update a membership by ID. |
| User Activity | Participant joined a meeting | A participant join the meeting. |
| User Activity | Participant left a meeting | A participant left the meeting. |
| File activity | Upload file | A file is uploaded in chat. |
| File activity | Delete file | A file is deleted from chat. |
