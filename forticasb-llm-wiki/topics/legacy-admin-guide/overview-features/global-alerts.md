# Global Alerts (Legacy FortiCASB 24.4.b)

Overview features are not specific to a single cloud account; they use data collected from all cloud accounts onboarded in FortiCASB. Overview topics in the guide: Activate and Generate Reports, View FortiCASB Audit logs, Shadow IT Discovery, App Events Supported by FortiCASB, Fabric Integration Configuration. Screenshots were not extracted. [src: forticasb-admin-guide-24-4-b, p.293]

## Location
Global Alert is at **Overview > Alert**. It combines all alerts from all supported onboarded cloud applications in one view.

## Alert types
| Type | Generated by |
|---|---|
| Data Analysis | Data Security Policies created in **Data Protection > Policies > Data Policies** |
| Threat Protection | Threat Protection policies; configured per cloud app account under **Policy > Threat Protection** |
| Compliance | Compliance policies; configured per cloud app account under **Policy > Compliance** |

Click any of the three alert types to filter by type. [src: forticasb-admin-guide-24-4-b, p.294]

## Applications supported by Threat Protection and Compliance policies
Salesforce, Office 365, Box, Dropbox, Confluence, Egnyte, GitHub, Jira, SAP IAS, ServiceNow, Webex Teams, Zoom. (Google Workspace is not in this list in the guide.) [src: forticasb-admin-guide-24-4-b, p.295]

## Alert filters
Click **+Add Filter**, choose an attribute, then click the search button.
- **Activity Type**: filter by specific cloud application account activity.
- **Policy/Patterns**: filter by specific policy of the cloud application account.
- **Alert ID**: each alert has its own alert ID.
- **SaaS application**: filter by cloud application account (e.g. Office 365 shows only Office 365 alerts).
