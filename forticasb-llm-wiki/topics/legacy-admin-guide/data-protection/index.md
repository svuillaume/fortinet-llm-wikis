# Data Protection (legacy FortiCASB 24.4.b)

Data Protection is described in the guide as the fundamental feature set where SaaS application data is monitored and protected through Data Protection Policy and analyzed through Files and Discovery. Screenshots in the guide were not extracted; this wiki contains text only. [src: forticasb-admin-guide-24-4-b, p.353]
