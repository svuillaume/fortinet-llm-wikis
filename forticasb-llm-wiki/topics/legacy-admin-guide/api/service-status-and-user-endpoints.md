# Service, Status, Severity and User Endpoints

Authentication and header conventions: [overview-and-authentication.md](overview-and-authentication.md). All requests carry `Authorization: Bearer <Authorization Token>` and `Content-Type: application/json`; `companyId`, `roleId` and `buId` come from Get Resource Map.

## Get Service History

Gets the cloud service OAuth history of the business unit.

- URL: `/api/v1/service/history/{application}`
- Method: GET

### Request headers

| Key | Value | Type | Description |
|---|---|---|---|
| Authorization | Bearer `<Authorization Token>` | String | Credential generated by FortiCASB |
| Content-Type | application/json | String | |
| buId | `<Business Unit ID>` | Long | Target business unit ID |
| application | `<Cloud Service application>` | String | Application name such as Salesforce, Office365 (also the `{application}` path segment) |
| companyId | `<Company ID>` | Integer | Company ID |
| roleId | `<User ID>` | Integer | Login user ID |

### Sample request

```
GET https://www.forticasb.com/api/v1/service/history/Salesforce
Authorization: Bearer <Authorization_Token>
Content-Type: application/json
buid: 6384
companyId: 62598
roleId: 36241
```

### Response variables

| Name | Required | Type | Description |
|---|---|---|---|
| id | Required | long | OAuth history ID |
| buId | Required | Long | Business unit ID |
| application | Required | String | Cloud service application name |
| scanId | Optional | String | Application name + company name |
| actionStatusCode | Optional | String | Guide describes it as "the user name registered with this cloud service" (sample shows `Success`; description appears mismatched) |
| message | Optional | String | Message returned for the service status history |
| date | Optional | long | Timestamp when this step was processed |
| lastStep | Optional | String | Last process step |
| casbUser | Optional | String | User email used in FortiCASB |
| cloudUser | Optional | String | User name registered in the cloud service account |

## Get Application Status

Gets cloud service information and authentication status under the same business unit.

- URL: `/api/v1/application/status`
- Method: GET

### Request headers

| Key | Value | Type | Description |
|---|---|---|---|
| Authorization | Bearer `<Authorization Token>` | String | Credential generated by FortiCASB |
| Content-Type | application/json | String | |
| buId | `<Business Unit ID>` | Long | Target business unit ID |
| companyId | `<Company ID>` | Integer | Company ID |
| roleId | `<User ID>` | Integer | Login user ID |

### Sample request

```
GET https://www.forticasb.com/api/v1/application/status
Authorization: Bearer <Authorization_Token>
Content-Type: application/json
roleId: 36241
companyId: 62598
buid: 84
```

### Response variables

| Name | Required | Type | Description |
|---|---|---|---|
| service | Required | String | Cloud service such as "Salesforce", "Office365" |
| applicationId | Required | String | ID of the cloud service account |
| applicationStatus | Required | int | Onboarding status of the cloud service account (sample shows the string `RUNNING`) |
| cloudAccount | Required | String | Cloud service account username |

The sample also shows `companyId`, `buId`, `update`, `enable` and `lastUpdate`, which are not described in the guide.

## Get Severity

Gets all alert severity definitions from FortiCASB.

- URL: `/api/v1/severity`
- Method: GET

### Request headers

| Key | Value | Type | Description |
|---|---|---|---|
| Authorization | Bearer `<Authorization Token>` | String | Credential generated by FortiCASB |
| Content-Type | application/json | String | |
| companyId | `<Company ID>` | Integer | Company ID |
| roleId | `<User ID>` | Integer | Login user ID |

### Sample request

```
GET https://www.forticasb.com/api/v1/severity
Authorization: Bearer <Authorization_Token>
Content-Type: application/json
roleId: 36241
companyId: 62598
```

### Response variables

| Name | Type | Description |
|---|---|---|
| id | String | Severity code; the "Severity" code filter for alerts |
| name | String | Severity name; the "Severity" name filter for alerts |

### Sample response

```json
[
  {"id":"1","name":"Critical"},
  {"id":"2","name":"Alert"},
  {"id":"3","name":"Warning"},
  {"id":"4","name":"Information"},
  {"id":"5","name":"Pass"}
]
```

## Get User List

Gets details of all users of the cloud services under the same company and business unit.

- URL: `/api/v1/profile/user/list`
- Method: GET

### Request headers

| Key | Value | Type | Description |
|---|---|---|---|
| Authorization | Bearer `<Authorization Token>` | String | Credential generated by FortiCASB |
| Content-Type | application/json | String | |
| companyId | `<Company ID>` | Integer | Company ID |
| roleId | `<User ID>` | Integer | Login user ID |
| buId | `<Business Unit ID>` | Long | Target business unit ID |
| service | `<Cloud Service>` | String | Cloud service name such as Salesforce, Office365 |
| skip | `<Skip Number>` | Integer | Index in the result set; excludes the first N items |
| limit | `<Limit per Page>` | Integer | Maximum items per page |

### Sample request

```
GET https://www.forticasb.com/api/v1/profile/user/list
Authorization: Bearer <Authorization_Token>
Content-Type: application/json
companyId: 62598
roleId: 36241
service: Salesforce
buid: 8
companyid: 7
skip: 0
limit: 2
```

### Response variables

| Name | Required | Type | Description |
|---|---|---|---|
| companyId | Required | String | Company ID |
| userId | Required | String | User identity |
| origUserId | Required | String | Original user identity |
| deleted | Required | boolean | Whether the user information is deleted |
| createdDate | Required | long | Timestamp, user created date |
| service | Required | Application | Cloud service name |
| isActive | Required | boolean | User active status |
| buId | optional | Long | Business unit ID |
| createdById | optional | String | ID that created this user |
| lastModifiedDate | optional | long | Timestamp of last modification |
| lastModifiedById | optional | String | Last user ID that modified this user |
| lastLoginDate | optional | long | Timestamp of last login to FortiCASB (as worded) |
| systemModstamp | optional | long | System timestamp |
| email | optional | String | Registered user email |
| userName | optional | String | Registered user name |
| name | optional | String | User's name |
| firstName | optional | String | First name |
| lastName | optional | String | Last name |
| userType | optional | UserTypeEnum | User type |
| profileId | optional | String | Profile ID |
| userRoleId | optional | String | Role ID |
