# Event and Filter Endpoints

Authentication and header conventions: [overview-and-authentication.md](overview-and-authentication.md).

## Get Event

Gets the activity event definitions from FortiCASB.

- URL: `/api/v1/event`
- Method: GET

### Request headers

| Key | Value | Type | Description |
|---|---|---|---|
| Authorization | Bearer `<Authorization Token>` | String | Credential generated by FortiCASB |
| Content-Type | application/json | String | |
| service | `<Cloud Service>` | String | Cloud service name such as Salesforce, Office365 |
| companyId | `<Company ID>` | Integer | Company ID; from Get Resource Map |
| roleId | `<User ID>` | Integer | Login user ID; from Get Resource Map |

### Sample request

```
GET https://www.forticasb.com/api/v1/event
Authorization: Bearer <Authorization_Token>
service: Salesforce
Content-Type: application/json
roleId: 36241
companyId: 62598
```

### Response variables

| Name | Type | Description |
|---|---|---|
| id | integer | Activity ID; used as "Activity ID" when filtering alerts and activity |
| name | String | Activity operation name ("Activity Name" filter) |
| nameEnum | OperationNameEnum | Activity operation type ("Activity" enum filter) |
| value | String | Activity ID ("Activity" filter) |
| category | String | Activity category ("Activity Category" filter) |
| searchField | String | Search field of the filter |

### Sample response (as printed in the guide; list is partial)

```json
[
  {"id":202,"name":"Upload File","nameEnum":"UPLOAD_FILE","value":"202","category":"FILE","searchField":"activity"},
  {"id":203,"name":"Download File","nameEnum":"DOWNLOAD_FILE","value":"203","category":"FILE","searchField":"activity"},
  {"id":206,"name":"Upload New Version","nameEnum":"UPLOAD_NEW_VERSION","value":"206","category":"FILE","searchField":"activity"}
]
```

## Get Filter List

Gets all user-created filter lists for the specified cloud service under the target business unit.

- URL: `/api/v1/filter/list`
- Method: GET

### Request headers

| Key | Value | Type | Description |
|---|---|---|---|
| Authorization | Bearer `<Authorization Token>` | String | Credential generated by FortiCASB |
| Content-Type | application/json | String | |
| buId | `<Business Unit ID>` | Long | Target business unit ID |
| service | `<Cloud Service Name>` | String | Cloud service name such as Salesforce, Office365 |
| companyId | `<Company ID>` | Integer | Company ID |
| roleId | `<User ID>` | Integer | Login user ID |

### Sample request

```
GET https://www.forticasb.com/api/v1/filter/list
Authorization: Bearer <Authorization_Token>
Content-Type: application/json
buid: 6384
service: Office365
roleId: 36241
companyId: 62598
```

### Response variables

| Name | Type | Description |
|---|---|---|
| id | Integer | Serial number |
| name | String | Filter name created by the user |
| filter | String | Saved filter (a JSON document serialized as a string) |
| source | String | Page the filter was saved from |
