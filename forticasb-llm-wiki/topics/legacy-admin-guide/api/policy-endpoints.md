# Policy Endpoints

Authentication and header conventions: [overview-and-authentication.md](overview-and-authentication.md). All requests carry `Authorization: Bearer <Authorization Token>` and `Content-Type: application/json`. In each guide section the response-variable table lists only three fields, while the sample response contains many more; the extra fields are not described in the guide ("not found in sources").

## Get Data Security Policy List

Returns all FortiCASB Data Security Policies and details from Data Protection.

- URL: `/api/v1/scan/policy/list`
- Method: GET

### Request headers

| Key | Value | Type | Description |
|---|---|---|---|
| Authorization | Bearer `<Authorization Token>` | String | Credential generated by FortiCASB |
| Content-Type | application/json | String | |
| buId | `<Business Unit ID>` | Long | Target business unit ID |
| companyId | `<Company ID>` | Integer | Company ID |
| roleId | `<User ID>` | Integer | Login user ID |

### Sample request

```
GET https://www.forticasb.com/api/v1/scan/policy/list
Authorization: Bearer <Authorization_Token>
Content-Type: application/json
buid: 6384
service: Salesforce
roleId: 36241
companyId: 62598
```

### Response variables

| Name | Type | Description |
|---|---|---|
| name | String | Data Security Policy name |
| category | String | Category of the policy |
| code | String | Policy code identifying the policy |

## Get Threat Protection Policy List

Returns all FortiCASB Threat Protection Policies and details of the specified cloud service account.

- URL: `/api/v1/policy/tpList` (the sample request spells it `/api/v1/policy/tplist`)
- Method: GET

### Request headers

| Key | Value | Type | Description |
|---|---|---|---|
| Authorization | Bearer `<Authorization Token>` | String | Credential generated by FortiCASB |
| Content-Type | application/json | String | |
| buId | `<Business Unit ID>` | Long | Target business unit ID |
| service | `<Salesforce>` | String | Cloud service account |
| companyId | `<Company ID>` | Integer | Company ID |

### Sample request

```
GET https://www.forticasb.com/api/v1/policy/tplist
Authorization: Bearer <Authorization_Token>
Content-Type: application/json
buid: 6384
service: Office365
companyId: 62598
```

### Response variables

| Name | Type | Description |
|---|---|---|
| name | String | Threat Protection Policy name |
| policyCategory | String | Category of the policy |
| policyId | String | Policy ID identifying the policy |

| service | `<Salesforce>` | String | Cloud service account |
