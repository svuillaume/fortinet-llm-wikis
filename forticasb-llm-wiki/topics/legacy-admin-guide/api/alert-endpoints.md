# Alert Endpoints

Authentication and header conventions are described in [overview-and-authentication.md](overview-and-authentication.md). The sample response is shortened: the guide shows three near-identical alert objects, only the first is reproduced.

## Post Alert List

Gets cloud service account alert details.

- URL: `/api/v1/alert/list`
- Method: POST

### Request headers

| Key | Value | Type | Description |
|---|---|---|---|
| Authorization | Bearer `<Authorization Token>` | String | Authorization credential generated by FortiCASB |
| Content-Type | application/json | String | |
| companyId | `<Company ID>` | Integer | Company ID the business unit belongs to; from Get Resource Map |
| roleId | `<User ID>` | Integer | Login user ID; from Get Resource Map |
| buId | `<Business Unit ID>` | Long | Target business unit ID; also available from Get Resource Map |

### Request body parameters

| Name | Required | Type | Description |
|---|---|---|---|
| service | `<Cloud Service>` (required marking not clear in extraction; reconstructed as required) | String | Cloud service name such as Salesforce, Office365 |
| startTime | Required | long | Timestamp; filter to get alerts opened after this time |
| endTime | Required | long | Timestamp; filter to get alerts opened before this time (guide text says "before start date") |
| skip | Required | integer | Index in the result set; excludes the first N items |
| limit | Required | integer | Maximum number of items returned |
| user | Optional | List<String> | Filter by user email |
| policy | Optional | List<String> | Filter by alert id (as worded in the guide) |
| activity | Optional | List<String> | Filter by activities |
| objectIdList | Optional | List<String> | Filter by object identity |
| objectName | Optional | String | Filter by object name |
| severity | Optional | List<String> | Filter by severity |
| status | Optional | List<String> | Filter by status |
| idList | Optional | List<String> | Filter by alert IDs |
| alertType | Optional | List<String> | Filter by alert types |
| countryList | Optional | List<String> | Filter by countries |
| asc | Optional | String | Sort ascending. Options: `policyName` (policy that triggered the alert), `severity`, `createTimestamp` (alert creation time), `timestamp` (last updated) |
| desc | Optional | String | Sort descending; same options as `asc` |

### Sample request

```
POST https://www.forticasb.com/api/v1/alert/list
Authorization: Bearer <Authorization_Token>
Content-Type: application/json
buid: 6384
service: Salesforce
roleId:36241
companyId: 62598
```

### Response variables

| Name | Type | Description |
|---|---|---|
| buId | Long | Business ID |
| companyId | String | Company ID |
| id | String | Alert ID |
| object | String | Object name that triggered the alert |
| objectType | String | Object type of alert |
| objectId | String | Object id that triggered the alert |
| severity | String | Severity of the alert |
| serviceId | String | ID to distinguish different accounts of the cloud service |
| violationActivity | String | Activity violation that triggered the alert |
| displayOperation | String | Operation that triggered the alert |
| createTime | long | Alert creation time (UTC timestamp) |
| updateTime | long | Alert update time (UTC timestamp) |
| policyName | String | Violation policy name |
| policyId | String | Name of the policy the alert was triggered by (as worded; sample shows a numeric ID) |
| policyCode | String | ID of the policy the alert was triggered by (as worded; sample shows e.g. FC-ACT-010) |
| contextName | String | Context name of violation policy |
| userId | String | ID of the user who triggered the alert |
| eventId | String | ID of the event |
| eventIdList | Array | List of event IDs |
| service | Application | Cloud service |
| resultDesc | String | Description of the violation context |
| geoLocationList | Array | Place where the activity occurred |
| alertType | String | Classification of the alert |
| alertSubType | String | Sub classification of the alert |
| defineType | String | Policy type, predefined or customized |
| state | String | Alert state |
| totalPage | long | Total pages of alert results |
| skip | integer | Index in the result set |
| limit | integer | Maximum alerts returned in one page |
| totalCount | integer | Total number of activities on file |
| user | String | Registered user name of FortiCASB |
| userName | String | Registered user email of FortiCASB |
