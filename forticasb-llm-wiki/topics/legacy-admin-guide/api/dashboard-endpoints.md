# Dashboard Endpoints

Authentication and header conventions: [overview-and-authentication.md](overview-and-authentication.md). Every call needs `Authorization: Bearer <Authorization Token>` and `Content-Type: application/json`, plus the headers listed per endpoint. `companyId`, `roleId` and `buId` come from Get Resource Map. The `timeZone` header is the numeric time zone of the user, for example `+0800`. Some sample responses are shortened; where so, it is noted.

## Post Dashboard Risk

Gets risk trend data for all monitored accounts in the business unit.

- URL: `/api/v1/dashboard/risk`
- Method: POST

### Request headers

| Key | Value | Type | Description |
|---|---|---|---|
| Authorization | Bearer `<Authorization Token>` | String | Credential generated by FortiCASB |
| Content-Type | application/json | String | |
| buId | `<Account Number>` | Long | Target business unit ID |
| timeZone | `<Time Zone>` | String | Numeric time zone of the user, e.g. +0800 |
| companyId | `<Company ID>` | Integer | Company ID |
| roleId | `<User ID>` | Integer | Login user ID |

### Request body parameters

| Name | Required | Type | Description |
|---|---|---|---|
| startTime | Required | long | Timestamp, start of the filtered open alerts |
| endTime | Required | long | Timestamp, end of the filtered open alerts |

### Sample request

```
POST https://www.forticasb.com/api/v1/dashboard/risk
Authorization: Bearer <Authorization_Token>
Content-Type: application/json
roleId: 36241
companyId: 62598
buid: 6384
timezone: -0700
```

```json
{
  "startTime":1585518361548,
  "endTime":1585604761548
}
```

### Response variables

| Name | Type | Description |
|---|---|---|
| name | String | Cloud service name |
| id | String | Risk sequence number |
| key | String | Time the risk was detected |
| value | long | Risk count at that time |

### Sample response (shortened to Box and Salesforce; the guide also lists Dropbox, Google and Office365 with the same structure)

```json
{
  "data":[
    {
      "name":"Box",
      "values":[
        {"id":"0","key":"2020-03-10T18:00:00+0000","value":0},
        {"id":"1","key":"2020-03-10T18:30:00+0000","value":0}
      ]
    },
    {
      "name":"Salesforce",
      "values":[
        {"id":"0","key":"2020-03-10T18:00:00+0000","value":0},
        {"id":"1","key":"2020-03-10T18:30:00+0000","value":0}
      ]
    }
  ]
}
```

## Post Dashboard Statistics

Gets key statistics from the cloud service in the business unit.

- URL: `/api/v1/dashboard/statistics`
- Method: POST

### Request headers

| Key | Value | Type | Description |
|---|---|---|---|
| Authorization | Bearer `<Authorization Token>` | String | Credential generated by FortiCASB |
| Content-Type | application/json | String | |
| buId | `<Business unit ID>` | Long | Target business unit ID |
| timeZone | `<Time Zone>` | String | Numeric time zone of the user, e.g. +0800 |
| service | `<Salesforce>` | String | Cloud service account |
| companyId | `<Company ID>` | Integer | Company ID |
| roleId | `<User ID>` | Integer | Login user ID |

### Request body parameters

Required column is not present in the guide for this endpoint.

| Name | Type | Description |
|---|---|---|
| startTime | long | Timestamp, start of the filtered open alerts |
| endTime | long | Timestamp, end of the filtered open alerts |

### Sample request

```
POST https://www.forticasb.com/api/v1/dashboard/statistics
Authorization: Bearer <Authorization_Token>
Content-Type: application/json
timeZone: +0800
Service: Salesforce
buid: 6384
roleId: 36241
companyId: 62598
```

```json
{
  "startTime":1583865778729,
  "endTime":1583952178729
}
```

### Response variables

| Name | Type | Description |
|---|---|---|
| topRiskUsers | List | Top risk users in the period |
| topRiskObjects | List | Top risk objects in the period |
| topHitPolicies | List | Top hit policies in the period |
| topRiskEventType | List | Top risk event types in the period |
| topRiskPositions | List | Top risk positions in the period |
| topActivityPositions | List | Top activity positions in the period |
| alertTrend | List | Alert trend in the period |
| usageTrend | List | Usage trend in the period |
| riskSeverity | List | Risk severity statistics |
| name | String | Position of the alert |
| id | String | ID of the event, policy, risk user, risk object or risk position |
| key | String | Event name, risk user name, policy name, activity name, alert name, risk object name or trend time |
| value | long | Count of the statistic item |

## Get Dashboard Summary

Gets the dashboard summary.

- URL: `/api/v1/dashboard/summary`
- Method: GET

### Request headers

| Key | Value | Type | Description |
|---|---|---|---|
| Authorization | Bearer `<Authorization Token>` | String | Credential generated by FortiCASB |
| Content-Type | application/json | String | |
| buId | `<Business Unit ID>` | Long | Target business unit ID |
| companyId | `<Company ID>` | Integer | Company ID |
| roleId | `<User ID>` | Integer | Login user ID |

### Sample request

```
GET https://www.forticasb.com/api/v1/dashboard/summary
Authorization: Bearer <Authorization_Token>
Content-Type: application/json
companyId: 6
buid: 6384
companyId: 62598
roleId: 36241
```

(The guide's sample lists `companyId` twice, with values 6 and 62598.)

### Response variables

| Name | Type | Description |
|---|---|---|
| loginUser | String | Login user e-mail |
| alertsCount | long | Alerts in the last 30 days |
| activitiesCount | long | Activities in the last 30 days |
| fileScannedCount | long | Files scanned in the last 30 days |

### Sample response

```json
{
  "loginUser":"qa.casb1@gmail.com",
  "alertsCount":3220,
  "activitiesCount":9514,
  "fileScannedCount":340
}
```
