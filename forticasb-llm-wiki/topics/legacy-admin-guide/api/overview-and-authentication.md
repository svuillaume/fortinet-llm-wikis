# API Overview and Authentication

Screenshots were not extracted. Long sample tokens are abbreviated with `...`.

## Overview

FortiCASB service endpoints accept HTTP requests through REST APIs. A single endpoint and a single access (bearer) token cover all service endpoints. Every REST call (GET, POST, etc.) requires the bearer token in an HTTPS request. [src: forticasb-admin-guide-24-4-b, p.471]

## Authorization methods

1. **Client credential**: generate a credential in FortiCASB once (guide: "Generate API Credential", p.45), then use it permanently (until revoked) to obtain bearer tokens via [Get Credentials Token](#get-credentials-token).
2. **Username and password**: obtain a token via [Get Authorization Token](#get-authorization-token).
3. **Refresh token**: after method 1 or 2, use the refresh token in the response to get more bearer tokens via [Post Refresh Token](#post-refresh-token). The refresh token expires 8 hours after generation.

[src: forticasb-admin-guide-24-4-b, p.471]

## Request headers

Requests go over HTTPS. Request body is optional depending on the API; some parameters are required, others optional. Five headers are commonly used; the first three are default.

| Header | Description |
|---|---|
| Host | Domain name of the REST service endpoint or IP address |
| Authorization | Bearer token from a get-token method |
| Content-Type | Default `application/json` |
| Company ID (`companyId`) | Company of the user/credential; from [Get Resource Map](#get-resource-map) |
| Role ID (`roleId`) | Login user ID; from Get Resource Map |
| Business Unit ID (`buId`) | Business unit the user can access; from Get Resource Map |

Example GET request:

```
GET /api/v1/country/list? HTTP/1.1
Host: www.forticasb.com
Authorization: Bearer eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9...
Content-Type: application/json
```

Part of the response:

```json
[
  {
    "id":"US",
    "country":"United States of America"
  }
]
```

[src: forticasb-admin-guide-24-4-b, p.472-473]

## API throttling

FortiCASB limits requests to 100 TPM (100 requests per minute). [src: forticasb-admin-guide-24-4-b, p.473]

## Get Authorization Token

Get an access token using FortiCASB username and password.

- URL: `/api/v1/auth/token`
- Method: POST
- Header: `Content-Type: application/x-www-form-urlencoded`

| Body parameter | Required | Value | Description |
|---|---|---|---|
| grant_type | Required | password | |
| username | Required | `<username>` | FortiCASB account user name |
| password | Required | `<password>` | FortiCASB account password |

Sample request:

```
POST https://www.forticasb.com/api/v1/auth/token
Content-Type: application/x-www-form-urlencoded

grant_type: password
username: XXXXXXXXXX
password: XXXXXXXXXX
```

| Response variable | Type | Description |
|---|---|---|
| access_token | String | Access token returned |
| refresh_token | String | Refresh token returned |
| token_type | String | Type of token |
| expires | String | Timestamp when the token expires |

```json
{
  "token_type": "bearer",
  "expires": 1.585002117836E12,
  "access_token": "eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9...",
  "refresh_token": "I4WnuRUY0xHEsoNMDvmurq_J45VHyuxa4DRWq5mevlYB1YT1yL2TUAA8vRRNNyOyy5RwEww62j0cAM8yxa4B5kU8Gb..."
}
```

## Get Credentials Token

Get an OAuth 2.0 bearer token from credentials generated on FortiCASB.

- URL: `/api/v1/auth/credentials/token/`
- Method: POST

| Header | Value | Type | Description |
|---|---|---|---|
| Authorization | Basic `<FortiCASB credentials>` | String | Credential generated by FortiCASB |
| Content-Type | application/x-www-form-urlencoded | String | |

| Body parameter | Required | Value |
|---|---|---|
| grant_type | Required | client_credentials |

Sample request:

```
POST https://www.forticasb.com/api/v1/auth/credentials/token/
Authorization: Basic a0eddbf4-6840-4bb7-9789-acffd4ffac02
Content-Type: application/x-www-form-urlencoded

grant_type=client_credentials
```

Response variables: access_token (String), refresh_token (String), token_type (String), expires (String; expiry timestamp).

```json
{
  "token_type": "bearer",
  "expires": 1.585248581336E12,
  "access_token": "eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9...",
  "refresh_token": "I4WnuRUY0xHEsoNMDvmuronKCCut-9FKHZOT4Pfuancwh46UUz5irXDK98bRmDKREdg05VQ..."
}
```

[src: forticasb-admin-guide-24-4-b, p.475-476]

## Post Refresh Token

Use the short-lived refresh token from a prior token response to get a new access token without credentials or username/password.

- URL: `/api/v1/auth/token/refresh`
- Method: POST
- Header: `Content-Type: application/x-www-form-urlencoded`

| Body parameter | Required | Value | Description |
|---|---|---|---|
| grant_type | Required | refresh_token | |
| refresh_token | Required | `<Refresh Token>` | Refresh token from a past Get Authorization Token / Get Credentials Token response |

```
POST https://www.forticasb.com/api/v1/auth/token/refresh
Content-Type: application/x-www-form-urlencoded

grant_type: refresh_token
refresh_token: 2j0cAM8yxa4B5kU8GbTrty2kgSD7nfbmYEaPNQ
```

Response variables: access_token (String), token_type (String), expires (String).

```json
{
  "token_type": "bearer",
  "expires": 1.585002361532E12,
  "access_token": "eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9..."
}
```

[src: forticasb-admin-guide-24-4-b, p.476-478]

## Get Resource Map

Returns user and account basic information, including `companyId`, `roleId`, username and business unit IDs (`buId`), which are needed for many other APIs.

- URL: `/api/v1/resourceURLMap`
- Method: GET
- Headers: `Authorization: Bearer <Authorization Token>`, `Content-Type: application/json`

Sample request: `GET https://www.forticasb.com/api/v1/resourceURLMap`

| Response variable | Type | Description |
|---|---|---|
| resourceURL | String | API request endpoint |
| roleId | Long | Login user identity |
| username | String | Login user name |
| buMapSet.companyId | Long | Company ID the business unit is under |
| buMapSet.buId | Long | Business unit ID of the user account |
| buMapSet.buName | String | Business unit name |

```json
[
  {
    "resourceURL":"https://qa1.staging.forticasb.com",
    "roleId":1,
    "username":"casb qacasb1",
    "buMapSet":[
      {"buName":"research authentication","companyId":6,"buId":238187},
      {"buName":"aaa","companyId":6,"buId":6384}
    ]
  }
]
```
