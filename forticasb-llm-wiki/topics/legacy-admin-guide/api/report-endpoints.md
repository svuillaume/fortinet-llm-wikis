# Report Endpoints

Authentication and header conventions: [overview-and-authentication.md](overview-and-authentication.md). The three POST report endpoints share these headers; the sample requests in the guide also include a `service` header, which is not in the header table.

| Key | Value | Type | Description |
|---|---|---|---|
| Authorization | Bearer `<Authorization Token>` | String | Credential generated by FortiCASB |
| Content-Type | application/json | String | |
| buId | `<Business Unit ID>` | Long | Target business unit ID; also from Get Resource Map |
| roleId | `<User ID>` | Integer | Login user ID |
| companyId | `<Company ID>` | Integer | Company ID |

Request body parameter tables are not present in the guide for these endpoints (not found in sources); the fields below come from the samples.

## Post C-Level Report Summary

Returns all C-Level report instances generated on FortiCASB.

- URL: `/api/v1/report/clevel/page`
- Method: POST

### Sample request

```
POST https://www.forticasb.com/api/v1/report/clevel/page
Authorization: Bearer <Authorization_Token>
Content-Type: application/json
buid: 6384
service: Office365
companyId: 62598
roleid: 36241
```

```json
{"skip": 0, "limit": 1}
```

### Response variables

| Name | Type | Description |
|---|---|---|
| filename | String | C-Level report name (sample key is `name`) |
| date | String | Date the report was generated |
| id | String | ID of the report |

Other sample fields (`cLevel`, `status`, `finished`, `timezoneOffset`) are not described.

### Sample response

```json
{
  "data": {
    "datas": [
      {
        "id": 3840,
        "name": "2024 Annual",
        "date": "2024-01-13T00:29:14.556Z",
        "cLevel": true,
        "status": "completed_success",
        "finished": true,
        "timezoneOffset": 0
      }
    ],
    "totalPage": 0,
    "limit": 1,
    "skip": 0,
    "totalCount": 617
  },
  "code": 0,
  "msg": "success",
  "httpCode": 200
}
```

  "timezoneOffset": "-0800",

## Get Alert Report Summary

Returns alert report instances, filtered by year generated and whether the report is generated monthly.

- URL: `/api/v1/report/alert/reportList`
- Method: GET

### Request headers

| Key | Value | Type | Description |
|---|---|---|---|
| Authorization | Bearer `<Authorization Token>` | String | Credential generated by FortiCASB |
| Content-Type | application/json | String | |
| buId | `<Business Unit ID>` | Long | Target business unit ID |
| roleId | `<User ID>` | Integer | Login user ID |
| companyId | `<Company ID>` | Integer | Company ID |
| service | `<Salesforce>` | String | Cloud service account |
| year | `<Year>` | Integer | Year the report was generated |
| isMonthly | `<True>` | Boolean | True if the report is monthly, false otherwise |

### Sample request

```
GET https://www.forticasb.com/api/v1/report/alert/reportList
Authorization: Bearer <Authorization_Token>
Content-Type: application/json
buid: 6384
service: Salesforce
companyId: 62598
roleid: 36241
isMonthly: false
year: 2024
```

### Response variables

| Name | Type | Description |
|---|---|---|
| name | String | Alert report name |
| size | String | Size of the alert report (sample shows a number) |
| timestamp | String | Date the alert report was generated |

### Sample response

```json
{
  "data": [
    {"name": "Salesforce_Alert_Report20240101_UTC.csv", "size": 14108, "timestamp": "Jan 2, 2024, 9:18:06 PM"},
    {"name": "Salesforce_Alert_Report20240102_UTC.csv", "size": 15990, "timestamp": "Jan 3, 2024, 9:18:09 PM"},
    {"name": "Salesforce_Alert_Report20240103_UTC.csv", "size": 15116, "timestamp": "Jan 4, 2024, 9:18:06 PM"}
  ],
  "code": 0,
  "msg": "success",
  "httpCode": 200
}
```
