# Business Unit and Country Endpoints

Authentication and header conventions: [overview-and-authentication.md](overview-and-authentication.md). Company ID, role ID and business unit ID come from Get Resource Map.

## Get Business Unit Info

Gets details of the business unit.

- URL: `/api/v1/businessUnit/info`
- Method: GET

### Request headers

| Key | Value | Type | Description |
|---|---|---|---|
| Authorization | Bearer `<Authorization Token>` | String | Authorization credential generated by FortiCASB |
| Content-Type | application/json | String | |
| buId | `<Business Unit ID>` | Long | Target business unit ID; also from Get Resource Map |
| companyId | `<Company ID>` | Integer | Company ID the business unit belongs to |
| roleId | `<User ID>` | Integer | Login user ID |

### Sample request

```
GET https://www.forticasb.com/api/v1/businessUnit/info
Authorization: Bearer <Authorization_Token>
Content-Type: application/json
buid: 6384
companyId: 62598
roleId: 36241
```

### Response variables

| Name | Required | Type | Description |
|---|---|---|---|
| companyId | Required | Long | Company ID |
| companyName | Required | String | Registered parent company name in FortiCASB |
| buId | Required | Long | Business unit ID |
| displayName | Required | String | Business unit display name |
| region | Required | String | Registered region |
| companyEmail | Optional | String | Registered email |
| primary | Optional | Boolean | Whether it is the primary business unit |
| users | Optional | long | Number of users |

### Sample response

```json
{
  "companyId":6,
  "companyName":"qa",
  "buId":6384,
  "displayName":"aaa",
  "region":"global",
  "companyEmail":"",
  "primary":false,
  "users":0
}
```

## Get Country List

Gets a list of all countries.

- URL: `/api/v1/country/list`
- Method: GET

### Request headers

| Key | Value | Type | Description |
|---|---|---|---|
| Authorization | Bearer `<Authorization Token>` | String | Authorization credential generated by FortiCASB |
| Content-Type | application/json | String | |
| companyId | `<Company ID>` | Integer | Company ID |
| roleId | `<User ID>` | Integer | Login user ID |

### Sample request

```
GET https://www.forticasb.com/api/v1/country/list
Authorization: Bearer <Authorization_Token>
Content-Type: application/json
roleId: 36241
companyId: 62598
```

### Response variables

| Name | Type | Description |
|---|---|---|
| id | String | Country code; the value used as "Country" when filtering alerts |
| country | String | Country name; shown as "Country Name" when filtering alerts |

### Sample response

```json
[
  {"id":"AU","country":"Australia"},
  {"id":"CN","country":"China"},
  {"id":"DE","country":"Germany"},
  {"id":"ES","country":"Spain"},
  {"id":"JP","country":"Japan"},
  {"id":"US","country":"United States of America"}
]
```
