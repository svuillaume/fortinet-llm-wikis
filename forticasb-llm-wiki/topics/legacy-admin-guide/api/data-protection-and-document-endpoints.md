# Document Profile Endpoints

Authentication and header conventions: [overview-and-authentication.md](overview-and-authentication.md). Data security policy listing is in [policy-endpoints.md](policy-endpoints.md).

Both endpoints share the same request headers.

| Key | Value | Type | Description |
|---|---|---|---|
| Authorization | Bearer `<Authorization Token>` | String | Credential generated by FortiCASB |
| Content-Type | application/json | String | |
| buId | `<Business Unit ID>` | Long | Target business unit ID; also from Get Resource Map |
| service | `<Salesforce>` | String | Cloud service account |
| roleId | `<User ID>` | Integer | Login user ID |
| companyId | `<Company ID>` | Integer | Company ID |

## Post Document Profile Summary

Returns all document profile summaries of the specified cloud service account.

- URL: `/api/v1/profile/document/summary`
- Method: POST

### Request body parameters

The guide shows only a sample body and no parameter table (not found in sources); the fields below are taken from the sample.

| Name | Type | Description |
|---|---|---|
| limit | integer | Number of items (sample: 10) |
| skip | integer | Offset (sample: 0) |
| filterDataList | array | Filter objects; each has `name` (`File Type`, `Sensitive Data`, `Share Type`) and `valueList`; the latter two also have `byOthers` and `byAll` booleans |

### Sample request

```
POST https://www.forticasb.com/api/v1/profile/document/summary
Authorization: Bearer <Authorization_Token>
Content-Type: application/json
buid: 6384
service: Office365
companyId: 62598
roleid: 36241
```

```json
{
  "limit": 10,
  "skip": 0,
  "filterDataList": [
    {"name": "File Type", "valueList": []},
    {"name": "Sensitive Data", "valueList": [], "byOthers": false, "byAll": false},
    {"name": "Share Type", "valueList": [], "byOthers": false, "byAll": false}
  ]
}
```

### Response variables

| Name | Type | Description |
|---|---|---|
| name | String | Data type of the file |
| bubbleList | String | List of file types in the bubble diagram (sample shows an array of objects) |
| id | String | ID of the file type |

The sample also contains `bubbleOther`, `bubbleTotal` and `size`, which are not described in the guide.

## Post Document Profile List

Returns all document profile details of the specified cloud service account.

- URL: `/api/v1/profile/document/fileList`
- Method: POST

### Request body parameters

No parameter table in the guide (not found in sources); same structure as the summary request, per the sample.

| Name | Type | Description |
|---|---|---|
| limit | integer | Number of items (sample: 1) |
| skip | integer | Offset (sample: 0) |
| filterDataList | array | Same filter objects as in Post Document Profile Summary |

### Sample request

```
POST https://www.forticasb.com/api/v1/profile/document/fileList
Authorization: Bearer <Authorization_Token>
Content-Type: application/json
buid: 6384
service: Office365
companyId: 62598
roleid: 36241
```

```json
{
  "limit": 1,
  "skip": 0,
  "filterDataList": [
    {"name": "File Type", "valueList": []},
    {"name": "Sensitive Data", "valueList": [], "byOthers": false, "byAll": false},
    {"name": "Share Type", "valueList": [], "byOthers": false, "byAll": false}
  ]
}
```

### Response variables

| Name | Type | Description |
|---|---|---|
| filename | String | Name of the file (sample key is `fileName`) |
| fileId | String | ID of the file |
| service | String | Cloud service provider hosting the file |

Other fields in the sample (for example `dlp`, `exposure`, `sharing`, `sensitive`, `malware`, `states`, `processedResult`) are not described in the guide.
